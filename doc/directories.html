Directory Buffers

Directory buffers let you browse for files and perform basic file management functions.

You can open a directory buffer by specifying the name of the directory in the Open File dialog or on the command line when starting j. The command dir, mapped by default to Ctrl D, opens a directory buffer on the current directory.

The command dirHomeDir, available on the tool bar, opens a directory buffer on your home directory.

A dimmed hint over the listing shows the keys to open a file, go up, and see the rest, the ones for the edit mode you are in. It scrolls away with the listing.

The popup

? opens a popup of the directory's keys (modePopup):
  • Filters: s steps the sort through name, date and size; l (a in vim edit mode) types a pattern the listing is limited to, as dirLimit does (empty for all); . shows or hides the names that start with a dot.
  • Go: open, up, back, forward and home.
  • Files: tag, copy, move, delete, a shell command, and rescan.
Its keys are the listing's own in the edit mode in use, so each works with the popup closed too. A filter changes the listing at once and leaves the popup open, so several can be set; a command closes it. Escape closes it, as does a click outside it. ? opens this help; Ctrl H then a key opens the help for that key.

In vim edit mode the vim motions work here, and the commands below are on the keys listed under Edit Modes.

The following commands are specifically relevant to directory buffers:

  • dir
  • dirCopyFile
  • dirCycleSortBy
  • dirDeleteFiles
  • dirDoShellCommand
  • dirHomeDir
  • dirLimit
  • dirMoveFile
  • dirOpenFile
  • dirOpenFileAndKillDirectory
  • dirRescan
  • dirTagFile
  • dirToggleHidden
  • dirUnlimit
  • dirUpDir
