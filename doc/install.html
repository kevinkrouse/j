Installation

To compile from source, refer to the building documentation.

J runs on Linux, macOS and Windows.

Windows and macOS

Run the installer, J-1.0.0.exe or J-1.0.0.dmg. It brings its own Java runtime.

The binary archive

On any platform with Java 25 or later, unpack the binary distribution into a directory of its own and run the launcher: 

    $ mkdir j
    $ tar -xzf j-1.0.0-bin.tar.gz -C j
    $ ./j/j
The zip, j-1.0.0-bin.zip, holds the same files; on Windows run j\j.bat. The launcher passes the JVM options j needs and puts its extensions on the classpath. Running java -jar j/j.jar directly works too, but without those options window moves and resizes are dead under XWayland.

F1 brings up this guide, which j finds beside j.jar. If you move it, set docPath in your preferences file to the directory it is in: 

    docPath=C:\\j\\doc
On Windows, use double backslashes, as shown. Start j with --print-directories to see where the preferences file lives.
