Change Marks

A bar in the left margin marks each line changed since the file was loaded, in color.change, or once saved, color.savedChange. showChangeMarks turns them off. In a file git tracks, the marks are git's, against what is staged: see Change marks in the editor. The commands here work on either.

  • nextChange and previousChange (Ctrl Alt N and Ctrl Alt P; ]c and [c in vim edit mode) go to the first line of the next and previous change, around to the first past the last and the last before the first;
  • previewChange (<leader>hp in vim edit mode) shows the change at the caret, its removed and added lines with the characters that differ marked, in a window under the caret until the next command. Its bar has buttons for the previous and next change and to revert it, and in a file git tracks to stage or unstage it, to pick it in the git status, and where there are changelists, to move it to another; going to another change while it is open shows that one. While it shows, each button's key, p, n, r, s, u, ; and m, does what it does, where keys don't type text: in vim's normal mode, not its insert mode, nor in an edit mode without one;
  • revertLines (<leader>hr) puts the change at the caret, or the changes under the selection, back, an edit undo takes back;
  • a click on a mark (changePopup) shows its preview and a popup of these.
