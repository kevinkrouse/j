Building the Source

To install pre-built binary packages, refer to the install documentation.

Prerequisites

  • JDK 25 or later.
  • babashka.
  • gcc, for the optional jpty helper (unix only).
With Nix, nix develop provides all three.

Building

From the root of the source tree: 

    $ bb build
This compiles j to build/classes. bb jar builds build/j.jar. bb tasks lists every target.

Extensions

Each directory under extensions/ is built separately into build/lib/extensions/: 

    $ bb extensions
bb build also compiles jpty when gcc is available; shell and ssh buffers use it.

Running Tests

    $ bb test
    $ bb test-extensions

Running From Source

    $ bb run
This runs j with --debug --force-new-instance --no-session --no-server --no-restore, with a debugger listening on port 5005. bb run-core runs it with no extensions.

Building Distributions

    $ bb dist
or one at a time: bb dist-bin, bb dist-src, bb dist-mac, bb dist-win.
