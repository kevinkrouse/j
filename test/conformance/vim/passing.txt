# Conformance cases that are expected to pass, one name per line.
#
# A ratchet: a name is added when a milestone implements the feature that case
# covers. If a listed case stops passing the build fails. Cases not listed are
# free to fail while the modal engine is still being built --
# VimConformanceTest prints any that start passing.
#
# Promotion is deliberate, never automatic. While normal mode swallows keys it
# does not understand yet, any case whose expectation is "the document did not
# change" passes for the wrong reason; listing those would turn the ratchet
# into a source of false alarms once the feature really lands.
